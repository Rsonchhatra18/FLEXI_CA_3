## 📝 Summary

- RAG augments LLMs by retrieving relevant document chunks (via embeddings stored in a vector DB) and feeding them as context, which grounds answers, cuts hallucinations, and enables citations.  
- **Naïve RAG** simply inserts the top‑k retrieved chunks into the prompt; it’s fast but can’t detect irrelevant retrieval, leading to vague or hallucinated answers.  
- **Corrective RAG (CRAG)** adds a relevance‑grading step; irrelevant chunks are discarded, and if needed the query is rewritten or external sources are consulted before generation.  
- **Self‑RAG** performs a post‑generation check: the model verifies that its answer is supported by the retrieved context and, if not, regenerates or warns the user.  
- **Adaptive RAG** routes each query to the most efficient strategy (direct answer, vector store, calculation tool, etc.), saving tokens and avoiding unnecessary context.  
- Modern “agentic RAG” pipelines (e.g., with LangGraph) combine these techniques in a state‑machine graph, maintaining shared state, retries, and logging; running locally with Ollama keeps data private.  
- Practical defaults: chunk size ≈ 500–1000 chars with overlap, retain metadata for citations, cap retry loops, and log every step for debugging.

## 🔑 Key Terms

- **Retrieval-Augmented Generation (RAG)** – a technique that augments a language model with external documents retrieved from a vector store to ground its answers in real sources.  
- **Vector database** – a storage system that holds embedding vectors of document chunks, enabling fast similarity search for relevant context.  
- **Corrective RAG (CRAG)** – a RAG variant that grades retrieved chunks for relevance, rewrites queries or falls back to external sources when retrieval fails.  
- **Self-RAG** – a method where the model evaluates its own generated answer against the retrieved context and regenerates or warns if the answer is unsupported.  
- **Adaptive RAG** – a routing approach that selects the appropriate strategy (direct answer, retrieval, or tool use) per query to optimize efficiency and relevance.
